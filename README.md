# ReplyLab

ReplyLab is an experimental harness for two-seat chat. Each seat can be a human or an AI. Run the conversation one turn at a time or on autoplay, then branch from an earlier turn or a point inside a message to see what happens next.

- [Product specification](docs/product-spec.md) defines the user experience, replay semantics, and release criteria.
- [Technical specification](docs/technical-spec.md) defines the transcript model, adapter contract, command behavior, and implementation sequence.

Status: specifications for the first implementation.
